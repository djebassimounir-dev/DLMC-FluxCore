# DLMC-FluxCore
DLMC + FluxCore computational framework for galactic dynamics

## Description
Full computational framework for **Dynamic Local Mass Clustering (DLMC)** and the **FluxCore unified dark matter model**, designed for astrophysics, computational cosmology, and galactic dynamics analysis. Reproduce simulations, analyze baryonic contributions and gravitational dynamics, and generate publication-ready visualizations.

## Contents
- **Jupyter Notebooks (.ipynb)**: `dlmc-fluxcore.ipynb.ipynb`
- **Python scripts (.py)**: `script-dlmc+fluxcore.py`
- **Figures/Visualizations** (.png, .pdf, .html): `dlmc-fluxcore.pdf`, `dlmc-fluxcore.html`, `output_1_0.png` … `output_47_1.png`
- **LaTeX reports** (.tex, .pdf): `latex-dlmc-fluxcore.tex`
- **Markdown files** (.md): `dlmc-fluxcore.md`

## Usage
1. Open `dlmc-fluxcore.ipynb.ipynb` in **Jupyter Notebook**.
2. Run the cells to reproduce calculations and visualizations.
3. Use `script-dlmc+fluxcore.py` for batch simulations.
4. All figures, tables, HTML, and PDF outputs are reproducible from notebooks and scripts.
