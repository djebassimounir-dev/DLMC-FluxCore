# DLMC-FluxCore

DLMC + FluxCore computational framework for galactic dynamics.

This repository contains the **full computational framework** for **Dynamic Local Mass Clustering (DLMC)** and the **FluxCore unified dark matter model**, designed for astrophysics, computational cosmology, and galactic dynamics analysis.

---

## Contents

This repository includes:

- **Jupyter Notebooks** (`.ipynb`) to reproduce calculations and visualizations of galactic rotation curves and gravitational fluxes.
- **Python scripts** (`.py`) for batch simulations and automated analyses.
- **Figures and visualizations** (`.png`, `.pdf`, `.html`) for outputs of simulations and plots.
- **LaTeX reports** (`.tex`, `.pdf`) detailing methodology, equations, and results.
- **Markdown files** for supplementary notes (`.md`).

---

## Usage

1. Open `dlmc-fluxcore.ipynb.ipynb` in **Jupyter Notebook**.
2. Run the cells to reproduce all **calculations and visualizations**.
3. Use `script-dlmc+fluxcore.py` for **batch simulations** or automated analyses.
4. All outputs (figures, tables, HTML, PDF) are reproducible directly from the notebooks and scripts.
